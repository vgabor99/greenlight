# Fonts, icons and screen checks

`main/screen/bitmaps.c` and `bitmaps.h` are generated by `tools/gen_bitmaps.py` and committed. Never edit them by
hand: change the generator and rerun it. Sizes and what is drawn: docs/display.md#fonts-and-icons.

## Regenerate

Pillow is in a venv under `%TEMP%\gl_gen\venv` (create it if missing); fonts are downloaded into
`%TEMP%\gl_gen\fonts` (`GL_FONT_CACHE` overrides):

```
python -m venv %TEMP%\gl_gen\venv
%TEMP%\gl_gen\venv\Scripts\python -m pip install pillow
%TEMP%\gl_gen\venv\Scripts\python tools/gen_bitmaps.py
```

Then build. Commit the generator change and the regenerated files together.

## Add a line icon

The line icon table (`LINE_ICONS` in `tools/gen_bitmaps.py`) is **append-only**: HA's templates use the ids, so
never reorder or remove an entry. Add the new Material Design Icons 7.4.47 name at the end (no `-alert`
variants), regenerate, and:

1. add the id to the table in docs/data-model.md#line-icons;
2. add the icon with an example row to `DATA` in docs/uispec/mockups/icons.html;
3. add it to the name → id table in `greenlight_line_icon` in `ha/custom_templates/greenlight.jinja` (entities
   with that icon then get it), and if a rule should fall back to it, to the rules (and the id list in the
   comment); flash the firmware first, then deploy with the `deploy-ha` skill.

## Check against the mockups

The accepted designs are the mockups in docs/uispec/mockups/, described in docs/uispec/ui-spec.md (actual size,
1 bit).

1. Build with `idf.py -DSCREEN_DUMP=1 build` and flash. At boot it dumps every screen once with the mockups'
   content and edge cases (malformed line, unknown icon id, long name and state, empty state), then every frame
   sent to the panel.
2. `python tools/fb_dump.py --reset` (port COM5 by default, or a saved log file) writes
   `fb_<n>_<state>.png` into `%TEMP%\gl_test\frames`. Needs pyserial and Pillow.
3. Look at the PNGs next to the mockups. Expected differences: glyph hinting, text about 4 % narrower.
4. Build with `-DSCREEN_DUMP=0` again afterwards (CMake caches it; the dump slows every frame and can make HA's
   dataset commits time out).
